## 3. Walk-Forward Validation Framework (FROZEN)

### 3.1 Window Structure

**6 rolling windows**, each 6 months (180 days):

| Window | Start | End | Train Start | Train End | Status |
|--------|-------|-----|-------------|-----------|--------|
| W1 | 2020-06-01 | 2020-12-01 | 2017-06-01* | 2020-05-31 | rolling |
| W2 | 2020-12-01 | 2021-06-01 | 2018-06-01 | 2020-11-30 | rolling |
| W3 | 2021-06-01 | 2021-12-01 | 2019-06-01 | 2021-05-31 | rolling |
| W4 | 2021-12-01 | 2022-06-01 | 2020-06-01 | 2021-11-30 | rolling |
| W5 | 2022-06-01 | 2022-12-01 | 2021-06-01 | 2022-05-31 | rolling |
| W6 | 2022-12-01 | 2023-06-01 | 2022-06-01 | 2022-11-30 | rolling |

*W1 train window starts at data_start if <3 years available

**No lookahead bias**: Training data always ends before test window starts.

### 3.2 Per-Window Metrics (FROZEN)

For each test window, compute:

```
True Positives (TP):  BCE_score ≥ 5.0 AND price_bounce (20% recovery in next 30 days)
False Positives (FP): BCE_score ≥ 5.0 AND no bounce
False Negatives (FN): BCE_score < 5.0 AND bounce occurred
True Negatives (TN):  BCE_score < 5.0 AND no bounce

Precision  = TP / (TP + FP)
Recall     = TP / (TP + FN)
F1-score   = 2 × (Precision × Recall) / (Precision + Recall)
```

**Bounce Definition (FROZEN)**: 
- Price recovery ≥20% within 30 days after BCE signal (within test window or next 30 days)
- Measured from BCE signal date to peak within lookhead window

## 4. Validation Gates (FROZEN)

### 4.1 Framework Validation Gate (WFV Gate)

**Purpose**: Test that WFV framework itself is working (no lookahead bias, metrics computed correctly)

```
Gate Pass Criteria:
✓ F1_avg ≥ 0.55 (average F1 across 6 windows)
✓ F1_min ≥ 0.40 (no window fails badly)
✓ No lookahead bias detected (training < test)
✓ Refitting cadence = monthly (no data leakage)
```

**Status**: Framework gate is a **SANITY CHECK**, not alpha proof.

### 4.2 Operational Threshold (Component Gate)

**Purpose**: Entry signal validity (documented, not novel)

```
Gate Pass Criteria:
✓ BCE_score ≥ 5.0 (triggers entry signal in system)
✓ All 6 components scored (no missing fields)
✓ Score range 0-6 (no out-of-bounds)
```

**Status**: Operational, already in production (`bce_engine.py` line 25).

### 4.3 IMPORTANT — Distinction (FROZEN)

| Gate | Purpose | Metric | Threshold | Status |
|------|---------|--------|-----------|--------|
